**Neoraid**

A modern look for the Unraid 7.3 webGUI that keeps the Unraid palette. Light or dark follows *Settings → Display Settings* (white/azure = light, black/gray = dark); the switch in the navigation bar changes it for this browser. Accent colour, density, corners and font are in *Settings → Neoraid*. Uninstall the plugin to get the stock look back.
